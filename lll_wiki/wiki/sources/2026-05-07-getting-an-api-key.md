## TL;DR
- Guide pratica step-by-step per generare una chiave API da `console.anthropic.com`.
- La chiave è mostrata **una sola volta**: copiarla subito. Se persa, eliminare e rigenerare.

## Punti chiave

### Steps
1. Vai su `console.anthropic.com` e accedi.
2. Dashboard principale → pulsante "Get API Keys" (in alto a destra).
3. Pagina API Keys → "Create Key".
4. Seleziona workspace `Default`, assegna un nome (es. "Anthropic Course").
5. **Copia la chiave** dalla finestra popup — visibile solo in questo momento.

### Sicurezza
Conservare la chiave in un file `.env` fuori dal version control. Vedi [[wiki/concepts/api-key-security|API Key Security]].
